# 위시리스트 연결 안내

## 개발용 미리보기

`npm.cmd run dev`로 실행하면 실제 찜 목록이 비어 있을 때 임시 상품 9개가 자동 표시됩니다. 1페이지는 기존 6개, 2페이지는 나머지 3개이며 3~50페이지는 '표시할 상품이 없습니다.'로 표시합니다. 미리보기는 1~50페이지를 항상 제공하고 실제 찜 목록은 상품 수에 따라 계산합니다. 번호는 1~5, 6~10 등의 그룹으로 표시되고 화살표는 이전/다음 그룹의 첫 페이지로 이동합니다. 첫 그룹에서 이전, 마지막 그룹에서 다음 화살표는 비활성화됩니다. 상단의 **실제 찜 목록 보기**로 전환하면 기존 빈 목록 안내를 확인할 수 있습니다. 실제 찜 목록에 상품이 있으면 해당 목록이 먼저 표시됩니다.

미리보기 데이터는 `src/data/wishlistPreview.js`에 분리되어 있고 React 메모리에서만 관리합니다. 선택·담기·삭제와 초기화를 테스트할 수 있으며 실제 localStorage, 찜 목록, 장바구니는 변경하지 않습니다. 새로고침 시 임시 데이터는 초기화됩니다. 상품 링크는 실제 상세 화면으로 이동하지 않습니다.

개발 모드(`import.meta.env.DEV`)에서만 미리보기 컨트롤을 제공하며 배포 빌드에서는 실제 찜 목록만 표시됩니다. 실제 데이터 연결 후 Wishlist.jsx의 미리보기 래퍼/import와 CSS의 `wishlist-preview-controls`, 임시 데이터 파일을 제거하면 됩니다.

- 작업 경로: `/wishlist`. 기존 헤더/푸터는 그대로 사용합니다.
- `src/services/wishlistStore.js`의 `useShopping()`으로 찜 목록과 장바구니 상태를 구독합니다. 같은 탭과 다른 탭에서 상태가 갱신됩니다.
- 상품 형태: `{ id: string, name: string, price: number, originalPrice?: number, image?: string }`.
- 상품 목록/상세 팀에서 `addWishlistProduct(product)`와 `removeWishlistProducts([id])`를 사용하면 찜 상태가 일치합니다.
- `addCartProducts(products)`는 기존 상품의 수량을 1씩 늘립니다. 현재 장바구니 구현이 없어 정한 임시 규칙입니다. 찜 목록은 유지됩니다.
- 저장 키: `ongyeol.shopping.v1`. 값: `{ wishlist: [...products], cart: [...productsWithQuantity] }`. 첫 방문에는 찜 목록이 비어 있습니다. 저장 실패는 화면 안내로 표시합니다.
- `wishlistCatalog`는 피그마의 임시 상품 9종이며 찜 목록 개수와 무관합니다. 상품 이미지는 제공되지 않아 피그마처럼 회색 영역으로 표시합니다.
- `/products/:id`는 Wishlist.jsx의 임시 상세 화면입니다. 예: `/products/odi-cream`에서 찜하기를 누른 후 `/wishlist`에서 확인할 수 있습니다. 팀의 상세 페이지가 완성되면 App.jsx의 해당 라우트를 실제 컴포넌트로 교체하세요.
- 팀원의 Products.jsx, ProductDetail.jsx, Cart.jsx는 수정하지 않았습니다. 장바구니 화면은 아직 구현되어 있지 않으므로 해당 팀에서 위 저장 모듈을 연결해야 합니다.
- 페이지당 6개를 표시하며 전체 상품 수와 페이지 수는 동적입니다. 페이지 번호는 최대 5개이고, 빈 목록에도 페이지 번호 1과 비활성화된 이전/다음 화살표를 표시합니다. 페이지네이션은 항상 목록 하단 중앙에 표시됩니다. 이동 시 목록 상단으로 스크롤합니다. 전체 선택은 현재 페이지에 적용되고 페이지 이동 시 선택은 해제됩니다.
- 하트는 팝업 없이 즉시 찜을 해제합니다. 상품 아래 삭제 버튼과 선택 삭제는 확인 팝업을 유지합니다.
- 반응형: 835px 이상 3열, 600~834px 2열, 599px 이하 1열.

검증: `node --test src/services/wishlistStore.test.js`, `npm.cmd run build`, `npm.cmd run lint`.
수동 확인: 개별 선택 → 부분 선택 표시 → 전체 선택 → 일괄 담기 → 찜 유지/저장된 장바구니 수량 → 개별/일괄 삭제 → 새로고침. 10개 이상 상품에서 다음 페이지와 마지막 페이지 삭제를 확인하세요. 브라우저에서 1440px, 768px, 390px 크기로 확인하세요.
