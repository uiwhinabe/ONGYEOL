# AI 상담창 확인 결과

Figma MCP 노드 1069:2176 및 2106:4377 기준. 창 420×760px, 버튼 60×60px, 우측 정렬, 간격 57px. X는 제공 노드에 별도 상태가 없어 기존 hover-close.svg(31×31px)를 재사용했습니다. 호버의 색상·아이콘 전환과 translateY(-4px)는 유지하고 크기 변화는 제거했습니다.

Edge/Playwright에서 1440×1080, 834×1194, 390×844 화면을 확인했습니다. 모두 상담창 420×760px, 버튼 60×60px, 안내 글씨 14px로 동일합니다. 모든 상담창 이미지가 로드되고 배경 420×760px, 아바타 39px, 메뉴·전송 24px, 시계 18px로 표시됩니다.

열기 → X 전환 → 클릭 닫기 → 원래 버튼 복귀, Escape 닫기, 버튼 포커스 복귀, 검색 드롭다운 닫힘, 포인터가 밖으로 나가도 유지, 스크롤 전후 위치 동일, 닫힘 시 inert 적용을 확인했습니다. 상담창은 body 포털의 fixed 요소이며 레이아웃 공간을 차지하지 않습니다. 헤더 및 드롭다운(20–33) 위의 기존 채팅 z-index 40을 사용합니다. 현재 프로젝트에 별도 주요 모달은 없습니다.

잘림 기준(그림자 제외, 안전 영역 0px 기준):

- 화면 너비 835px 이상: 높이 955px 미만에서 위쪽 잘림.
- 화면 너비 834px 이하: 너비 444px 미만에서 왼쪽, 높이 901px 미만에서 위쪽 잘림.
- 390×844px에서는 왼쪽 54px, 위쪽 57px 잘림. 크기를 축소하지 않았습니다.
- 안전 영역이 적용되면 해당 여백만큼 잘림 기준이 증가합니다.

문의하기·대화·설정의 기존 화면/API는 없으므로 비활성 버튼으로 두고 AIChatWidget의 onInquiry/onConversation/onSettings 콜백 연결을 준비했습니다. AI API는 추가하지 않았습니다. 운영 문구는 Figma 원문 `AI 상담 : 24시간 연중무휴ㅇㅇㅇㅇㅇ`를 유지하고 178px 영역에서 말줄임합니다. 대화에 첨부 이미지는 전달되지 않았습니다.

프로젝트에 저장된 Noto Serif/Noto Sans 폰트 및 한글 Noto Sans KR 대체 글꼴을 재사용했습니다. 별도 Noto Serif Display/Medium 폰트 파일은 프로젝트에 없어 기존 글꼴의 variation 설정과 500 굵기를 사용합니다.

검증 스크립트 chat.cjs는 이 작업 환경의 Playwright 캐시와 설치된 Edge를 사용합니다. Vite 개발 서버(127.0.0.1:5173)가 켜진 상태에서 `node verification/chat.cjs`로 실행합니다.
